METODO CONSIGLIATO:
1. Estrai questo ZIP sul PC.
2. Usa GitHub Desktop per pubblicare/importare l'intera cartella del progetto.
3. NON caricare i singoli file Kotlin dalla pagina web di GitHub.
4. Controlla su GitHub che dentro app/ sia visibile build.gradle.kts.
5. Controlla che MainActivity.kt sia in:
   app/src/main/java/com/spectro/app/MainActivity.kt
6. I Repository Secrets devono essere:
   SPECTRO_KEYSTORE_B64
   SPECTRO_KEY_PASSWORD
7. Poi vai in Actions > Build Spectro Native APK > Run workflow.

Se su GitHub vedi AttachmentStore.kt, ClientsScreen.kt, Models.kt ecc. direttamente nella root,
il caricamento è ERRATO e il progetto è stato appiattito.
